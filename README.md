# downscaling-lst

[![DOI](https://zenodo.org/badge/1133780788.svg)](https://doi.org/10.5281/zenodo.19348084)

This repository contains code implementing a block-diagonal Gaussian process approach to downscaling remotely sensed land surface temperature data from the ECOSTRESS probe.

The `.json` files in in the `requests` folder can be submitted at [https://appeears.earthdatacloud.nasa.gov](https://appeears.earthdatacloud.nasa.gov) to reproduce our data.
